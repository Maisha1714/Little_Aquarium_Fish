# Little Reef Aquarium
Open `index.html` in any browser. No install or build needed.
Internet is only used for the Fredoka/Nunito fonts (falls back to system fonts offline).

Host it free: drag this folder onto Netlify Drop, or push to GitHub Pages / Vercel.

Add or edit fish: the `FISH` array near the bottom of index.html (facts, clues, sizes)
and the `ART` object (colours and body shape).
